COLLABORATIVE TASKMASTER STUDIO

Política de privacidad

Última actualización: 30 de agosto de 2026.

Esta política explica cómo Collaborative Taskmaster Studio trata la información cuando una persona inicia sesión, conversa con el asistente, adjunta archivos o conecta servicios externos.

Información que tratamos

  • Datos básicos de la cuenta de Google: nombre, correo electrónico, imagen de perfil e identificador de cuenta.
  • Conversaciones, diseños de agentes, archivos adjuntos y resultados que la persona decide aportar.
  • Datos consultados mediante conexiones autorizadas de Google Drive, Gmail y Calendar, únicamente para responder a solicitudes explícitas.
  • Datos técnicos mínimos necesarios para seguridad, diagnóstico y funcionamiento del servicio.

Cómo usamos la información

Usamos estos datos para autenticar a la persona, aislar su espacio, responder conversaciones, leer los recursos que seleccione, construir Taskmasters aprobados y proteger el servicio. No vendemos información personal ni la utilizamos para publicidad.

Acceso a servicios de Google

Las conexiones se realizan con OAuth y permisos de solo lectura. La aplicación solicita acceso a Drive, Gmail o Calendar únicamente cuando la persona elige conectar ese servicio. El acceso se usa para buscar y leer contenido solicitado dentro de la sesión; no se envían correos, no se modifican archivos y no se crean eventos con estos permisos.

El uso y transferencia de información recibida de las API de Google cumple la Política de datos de usuario de los servicios API de Google, incluidos sus requisitos de uso limitado.

Almacenamiento, seguridad y conservación

Las credenciales OAuth se cifran y se separan por cuenta. El contenido se conserva solo mientras sea necesario para prestar el servicio, mantener el historial solicitado y cumplir obligaciones de seguridad. La persona puede desconectar servicios, eliminar archivos y borrar conversaciones desde la aplicación.

Control de la persona usuaria

Es posible revocar el acceso desde la aplicación o desde la configuración de seguridad de la cuenta de Google. Para solicitar acceso, corrección o eliminación de datos, escribe a murcialobo@gmail.com.

Cambios y contacto

Podemos actualizar esta política cuando cambien las funciones o los requisitos aplicables. Publicaremos aquí la fecha de la versión vigente. Para consultas de privacidad o soporte, contacta a murcialobo@gmail.com.
